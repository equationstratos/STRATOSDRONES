A drone, fully in the open

The DJI Tello EDU is a brilliant learning platform — but it's a closed box. STRATOSDRONE keeps everything that made it great (the size, the SDK, the swarming) and opens all of it: schematic, PCB, CAD, firmware and a simulator, under permissive licenses.

01Same protocol

Speaks Tello SDK 2.0 on the wire — UDP 8889/8890/11111. Existing djitellopy scripts run unmodified, including the video stream.

02Simulate first

A full Gazebo Harmonic model runs the exact same fc_core flight code as the firmware. Fly the mission in sim, then on hardware — no rewrite.

03Actually buildable

KiCad board with a JLCPCB assembly package, OpenSCAD airframe → STL, and an ESP-IDF firmware tree. Nothing is hand-waved.

Specs vs DJI Tello EDU

Same flight envelope and Tello-compatible props, with a modern open brain: an ESP32-P4 doing flight + a hardware H.264 camera pipeline, paired with an ESP32-C6 for Wi-Fi 6.

Designed for the air

A clean swept "whoop" body — minimal, aggressive, airflow-optimised. The arms taper into the motor nacelles, the canopy crown is biased forward, and a removable shell clips on and off without screws so you can customise it like a Tello.

Removable canopy

Smooth Tello-style shell with a chamfered camera nose, swept side air intakes and LED light pipes. Snap posts mate with the deck — no screws, lift it off to swap or print a new one.

Rear slide-in battery

The 1S pack inserts from the rear exactly like a Tello, into a printed cradle with a positive stop. The compact 36×70 mainboard sits on M2 bosses above the under-body flow + ToF sensor window.

One frame, three protection levels

The airframe is parametric. Flip a single guard setting in params.scad and re-slice — the electronics, wheelbase and motor mounts stay identical across all three.

Naked none

Bare swept arms, no guards. The lightest, most minimal build — for open flying and maximum efficiency.

Ring guards ring

Thin open prop-guard rings on struts, Tello-style. Light protection for learning to fly and indoor knocks.

Cinewhoop duct

Full ducts with rounded intake lips and skids. Reinforced for indoor and contact flying, with a thrust bump from the shrouds.

How it's built

Five layers, one repository — each independently buildable and tested in CI.

◆fc_core — flight control

A platform-independent C99 core (no RTOS deps) compiled into both the ESP32-P4 firmware and the Gazebo plugin. Same code, same behaviour, in sim and in the air — with host-side closed-loop SIL tests.

◆Hardware — KiCad PCB

A compact 36×70 mm mainboard generated from a single design database (design.py → board, BOM, CPL, pinmap). ESP32-P4 + C6, MOSFET motor drivers, full IMU/baro/ToF/flow sensor suite. Order it assembled from JLCPCB.

◆CAD — parametric airframe

OpenSCAD whoop frame and canopy → STL. Three guard variants, rear battery bay, press-fit 8520 pockets and a removable shell — all from shared parameters.

◆Sim + SDK

Gazebo Harmonic twin with a Tello-protocol UDP endpoint and multi-drone swarms, plus stratospy — a thin add-on over djitellopy for the STRATOS extensions.

Every reference, mapped

A generated component map labels every part on both sides of the board so you can place and inspect it with confidence before ordering.

Routable by design

Passives are anchored around the ESP32-P4 with collision-aware placement — decoupling caps ring the MCU, zero copper overlaps.

Build your own

Everything you need is in the repository. The short version:

  1. Simulate it first. Build the Gazebo plugin, spawn a drone, and run python sdk/python/examples/01_hover.py — takeoff, hover, land, over the Tello protocol. No hardware required.
  2. Order the board. Review the KiCad project, then send the JLCPCB gerbers/BOM/CPL package off for assembly. Cross-check against the component map and KNOWN_GAPS.md before you commit.
  3. Print the airframe. Pick a guard variant, slice frame_<variant>.stl + canopy.stl in PETG or tough PLA — no supports, each part prints flat.
  4. Assemble. Press in the 8520 motors, mount the board on the M2 bosses, route the motor wires along the arms, slide in the 1S pack, clip on the canopy.
  5. Flash & fly. Build the ESP-IDF firmware for the ESP32-P4, flash, and connect — your simulated mission scripts now run on the real drone, unchanged.

⚠️ This is a flying machine with spinning props. Read docs/safety.md before the first flight — guards on, props off for the first power-up, proper LiPo handling.
